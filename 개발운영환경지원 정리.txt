--------------조원 역할 ----------------
레퍼토리 링크 복사하기 -> 폴더에 깃클론 하기 
본인 이름으로 브랜치만들고 이슈에 할일 넣어서 만들기 -> 할일 마다 커밋이 잡혀있어야함 
하단에 프로젝트가 잡히고 브랜치도 잡혀야함. 만들어진 브랜치에 연결

이클립스 실행 -> 작업 위치 확인. 깃 클론햇던 폴더, 백엔드가 워크 스페이스가 되야함 -> 그 안에 프로젝트 명 만들기 
-> 소스 트리 연결하기 -> 작업 위치 다시 잡고 -> 추가 버튼 -> 작업 위치는 백엔드 안으로  -> 소스트리는 .git이 있는 위치로 해야함
-> 패치, 풀 해서 동기화 하기 , 브랜치 받아오기 -> 다시 확인하기, 백엔드 까지가 워크스페이스임.// 소스트리는 .git 이 있는 위치임 
중요!! 둘이 같은 위치면 상관이 없음.,., 근데 다르면 분리해야함 

-- 예시: 자바 프로젝트 안에 자바가 있어서 같은 폴더에 .git 이 있었음 -> 백엔드 프론트엔드 작업 다르게 할시 이야기가 달라짐
-> 소스트리로 작업하는게 편함 , git 관리는 소스트리 

- 이클립스 에 자바 프로젝트 하나 만들어두기 (조장 역할!!!!!!!!!!) -> 안하면 복잡해짐!!!!!!!!!!!

(참고? 상위경로에 .git이 있어도 가능함 -> 이클립스 기준)
